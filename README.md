# CORSACARS

Jogo de condução 3D independente, desenvolvido para navegador com **Three.js** e **cannon-es**. **Não utiliza Unity** e não partilha ficheiros com o projeto Minecraft.

## Executar

Na pasta do repositório, inicia um servidor HTTP local (por exemplo `python -m http.server 8080`) e abre `http://localhost:8080`. É necessária ligação à Internet para carregar as bibliotecas JavaScript fixadas no `index.html`.

## Primeira fase

Primeiro objetivo: protótipo jogável com automóvel, física de rodas e suspensão, circuito de testes, terreno, dia/noite, várias câmaras, teclado/comando, HUD, pausa, definições e ecrã inteiro.

A versão inicial **não** é um simulador final nem promete gráficos de um AAA. O desenvolvimento será incremental. Consulta os controlos apresentados dentro do jogo.
